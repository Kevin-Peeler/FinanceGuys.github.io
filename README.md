## Client
**Wasatch Outfitters Collective (WOC)** is an outdoor recreation and retail company with three locations: Downtown SLC, Sandy, and Park City. It sells gear and runs rentals, repairs, guided trips, and corporate events.

## Problem Statement
WOC makes major capital purchases, such as e-bikes, premium ski equipment, and rental inventory upgrades, based on managers' experience and intuition rather than standardized financial analysis. Financial data is spread across disconnected spreadsheets, so executives can't consistently see which assets earn a return and which only add maintenance cost. With a fourth location planned, WOC needs a systematic, data-driven way to evaluate and approve capital investments.

## Consulting Question
How should WOC use financial data and decision support systems to evaluate capital investments and improve location-specific investment decisions?
